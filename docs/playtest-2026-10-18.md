## Automated checks

Run from repository root:

```sh
node --test tests/*.cjs
node --check game.js
node --check adventure.js
node --check sw.js
sh -n tools/make-voice.sh
sh -n tools/make-journey-voice.sh
git diff --check
```

All 25 tests passed. The adventure tests run real event handlers with a minimal
view harness, protecting progression, wrong answers, duplicate scoring, hints,
replay, sound ownership, rapid input, storage fallbacks and reset. They complement
the real-browser playthroughs; they do not pretend to validate real DOM layout.
The existing Canvas VM tests protect songs, multi-touch holds, audio interruption,
Find celebrations, drag inertia and lifecycle cleanup. Worker tests check every
precache asset exists, all prompt keys are cached, unrelated caches survive
activation and unsuccessful responses cannot overwrite successful cache entries.
